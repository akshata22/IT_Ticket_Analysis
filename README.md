# IT Tickets Analysis Dashboard

## Project Overview

This project presents an end-to-end analysis of an IT Tickets dataset, transforming raw operational data into meaningful business insights through data analysis, visualization, and interactive reporting.

The objective was to analyze IT support performance, identify operational trends, evaluate service quality, and design an interactive dashboard to help stakeholders monitor key performance indicators (KPIs) and make data-driven decisions.

---

## Repository Contents

### 📄 Documentation (.docx)

The documentation includes:

* Detailed answers to all project questions
* Business logic and justification for every solution
* Analysis methodology
* Insights and recommendations
* Supporting charts and visualizations

### 📊 Excel Workbook (.xlsx)

The Excel workbook is the primary project file and contains:

* Raw dataset
* Data cleaning and preparation
* Helper columns and calculations
* Pivot tables
* KPI calculations
* Interactive dashboard with slicers and charts

**To experience the complete dashboard functionality, open the Excel workbook, as the dashboard is fully interactive.**

### 📽️ Presentation (.pptx)

The presentation provides:

* Project overview
* Dashboard walkthrough
* Key business insights
* Dashboard screenshots
* Executive summary and recommendations

The analysis helped uncover trends related to:

* Ticket volume across different time periods.
* Resolution performance and turnaround times.
* Customer satisfaction patterns.
* Distribution of ticket priorities and severities.
* Performance across request categories and issue types.
* Operational workload trends.
* Areas requiring process improvements and resource optimization.
